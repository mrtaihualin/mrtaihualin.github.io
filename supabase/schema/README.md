## โฟลเดอร์นี้คืออะไร

ที่เก็บ **"แบบแปลน" ของฐานข้อมูล** — บอกว่ามีตารางอะไร แต่ละตารางมีคอลัมน์อะไร มีด่านอะไรกันอยู่

เปรียบเทียบ: ถ้าฐานข้อมูลคือตู้เก็บเอกสาร โฟลเดอร์นี้คือ**แบบแปลนตู้** — บอกว่ามีกี่ลิ้นชัก ล็อกยังไง แต่**ไม่มีเอกสารข้างในตู้** (นั่นต้องพึ่งระบบสำรองข้อมูล ซึ่งเป็นคนละเรื่อง)

## ⚠️ ยังทำไม่เสร็จ — ช่องโหว่ที่รู้ตัวแล้ว

### 1. ตัวนับเลขอัตโนมัติของ 9 ตาราง ยังขาด 🔴

ตารางเหล่านี้มีคอลัมน์ `id bigint not null` แต่**ไม่มีตัวนับเลขติดมาด้วย**:

```
classroom_recording_issues · classroom_recordings · game_sentences · game_words
login_events · payout_ledger · reading_sessions · star_fraud_alerts · star_ledger
```

**สาเหตุ:** Postgres มี 2 วิธีทำเลขอัตโนมัติ — คำสั่งที่ใช้ดึงจับได้แค่วิธีเก่า (`nextval`) จับวิธีใหม่ (`generated as identity`) ไม่ได้

**ผลถ้าเอาไปสร้างฐานข้อมูลใหม่ตอนนี้:** 9 ตารางนั้นเพิ่มแถวใหม่ไม่ได้เลย

**วิธีอุด** — รันคำสั่งนี้ใน SQL Editor (อ่านอย่างเดียว) แล้วส่งผลให้ AI เติมลงไฟล์ 01:

```sql
select c.relname as ตาราง,
       a.attname as คอลัมน์,
       case a.attidentity
         when 'a' then 'generated always as identity'
         when 'd' then 'generated by default as identity'
       end as คำสั่งที่ต้องเติม,
       case a.attgenerated when 's' then 'STORED (คอลัมน์คำนวณ)' end as หมายเหตุ
from pg_class c
join pg_namespace n on n.oid = c.relnamespace
join pg_attribute a on a.attrelid = c.oid and a.attnum > 0 and not a.attisdropped
where n.nspname = 'public' and c.relkind = 'r'
  and (a.attidentity <> '' or a.attgenerated <> '')
order by c.relname, a.attnum;
```

### 2. สิทธิ์ระดับตาราง (grant/revoke) เก็บไม่ครบ

จดไว้เป็นคอมเมนต์ในหัวข้อ `[99]` ของไฟล์ 01 เฉพาะ 3 ตารางที่ล็อก 2 ชั้น (`game_words`, `game_sentences`, `cron_state`) · ตารางที่เหลือใช้ค่าเริ่มต้นของ Supabase

### 3. ยังไม่มีระบบติดตามว่าไฟล์ไหนรันไปแล้ว

ตรวจแล้วพบว่าโครงการนี้ **ไม่มีระบบ migration เลย** (`supabase_migrations` ไม่มีอยู่จริง) — เป็นงาน `P2-05` ส่วนที่ยังรอ Lin อนุมัติ

## สิ่งที่โฟลเดอร์นี้ **ไม่ได้** แก้

**ไม่ได้แก้เรื่องข้อมูลหาย** — ไฟล์พวกนี้สร้างได้แค่ "ตู้เปล่า" ข้อมูลนักเรียนกับประวัติการจ่ายเงินยังต้องพึ่งระบบสำรองข้อมูลแยกต่างหาก
(แพ็กเกจฟรีของ Supabase **ไม่มีสำรองอัตโนมัติเลย** และไม่มี PITR — เรื่องนี้แยกไปทำในแชทอื่นแล้ว ดู `21_ระบบสำรองข้อมูล.md`)
