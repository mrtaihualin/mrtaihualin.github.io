> สร้าง 2026-07-31 · **อ่านไฟล์นี้ก่อนแก้ SQL ทุกครั้ง**
> ทำไมต้องมี: ปัญหาใหญ่ 2 ครั้งที่ผ่านมาเกิดจากเรื่องเดียวกัน — **ฟังก์ชันตัวเดียว มีโค้ดอยู่หลายไฟล์
> แล้วไม่มีใครรู้ว่าตัวไหนใหม่สุด** → เผลอรันไฟล์เก่าทับ = ของที่แก้ไปแล้วหายเงียบๆ หรือเว็บล่มทั้งระบบ

## 🔑 กฎ 3 ข้อ (ตั้ง 2026-07-31 ตามที่ Lin สั่ง)

1. **ฟังก์ชัน 1 ตัว = มีต้นฉบับล่าสุดอยู่ไฟล์เดียวเท่านั้น** — ดูได้จากตารางข้างล่าง
2. **แก้ฟังก์ชันไหนเสร็จ ต้องมาอัปเดตตารางข้างล่างทันที** ไม่งั้นสารบัญนี้จะกลายเป็นตัวหลอกแทนที่จะช่วย
3. **ก่อนกด Run ไฟล์ SQL ไหน เปิดดูหัวไฟล์ก่อนเสมอ** — ไฟล์ที่เลิกใช้แล้วจะมีป้าย 🛑 หรือ ⚠️ อยู่บรรทัดแรก
